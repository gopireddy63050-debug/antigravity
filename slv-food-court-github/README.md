# 🍲 SLV Food Court — Fresh Flavors, Endless Choice

An immersive, premium brand website for **SLV Food Court**, inspired by the Google Labs Pomelli brand book aesthetic. Combines bold brand identity, rich culinary storytelling, interactive 3D elements, real authentic menu board photography, and full portion-pricing controls.

---

## 🚀 Live Demo & Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **3D Graphics**: Three.js / React Three Fiber / Drei
- **Motion & Transitions**: Framer Motion & GSAP
- **Smooth Scroll**: Lenis
- **Icons**: Lucide React
- **Architecture**: 100% Client-Side / Zero External Backend / Zero DB

---

---

## 📦 Features

1. **Interactive 3D Centerpiece**: High-frame Three.js wok centerpiece with gold accents and 160 orbiting spice particles.
2. **Authentic Menu Board Dishes**: 22 authentic dishes cropped directly from the physical wooden board mounted on Old Jail Road.
3. **Real-time Portion Calculators**: Instant Full / Half price toggles for Noodles, Fried Rice, and Pizzas.
4. **Original Wall Board Lightbox**: View the official wall-mounted menu board at full resolution.
5. **WhatsApp Integration**: 1-click WhatsApp sharing link with pre-formatted rich message and direct counter chat (+91 79813 17324).
6. **Data Privacy Guarantee**: Zero tracking cookies, zero database logging, and isolated external connections.

## 🛠️ Local Development

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the website in your browser.

### 3. Build for Production
```bash
npm run build
npm start
```

---

## 🌐 Deploying to Vercel (Recommended)

1. Push or upload this repository to your **GitHub** account.
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import your GitHub repository.
4. Click **Deploy**. Vercel will automatically build the Next.js application and provide a free live URL (e.g., `https://slv-food-court.vercel.app`).
